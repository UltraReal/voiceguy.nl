# VoiceGuy Website

![VoiceGuy Logo](images/logo.png)

## 🌟 Project Overview

This is the official website for VoiceGuy, a voice-over artist and content creator. The site includes user authentication, profile management, admin dashboard, and social media integration.

## 🚀 Live Demo

[Visit the live site](#) (Coming soon)

## ✨ Features

- **User Authentication System**
  - Registration and login
  - Password recovery
  - User roles (admin/user)

- **Profile Management**
  - Customizable user profiles
  - Avatar uploads
  - Social media links

- **Admin Dashboard**
  - User management
  - Content management
  - Site settings

- **Social Media Integration**
  - TikTok, Twitch, and YouTube integration
  - Social media feeds

## 📋 Prerequisites

- PHP 7.4+
- MySQL 5.7+
- Web server (Apache/Nginx)

## 🔧 Installation

1. Clone this repository
2. Follow the instructions in [INSTALLATION.md](INSTALLATION.md)
3. Run the initialization script by visiting `init-project.php` in your browser
